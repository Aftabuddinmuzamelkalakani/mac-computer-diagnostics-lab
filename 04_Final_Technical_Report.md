## 1. Project Objective

The purpose of this project is to practice entry-level IT support and CompTIA A+ troubleshooting skills by inspecting a Mac computer, checking system information, testing network connectivity, and documenting the results.

- **Computer:** MacBook Pro (16-inch, 2023)

The project included checks of hardware information, memory, storage, operating system details, network interfaces, IP configuration, default gateway, network connectivity, and DNS configuration.
