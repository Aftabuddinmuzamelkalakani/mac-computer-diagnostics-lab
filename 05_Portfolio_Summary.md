# Mac Computer Diagnostics and IT Support Lab

**Project ID:** APLUS-LAB-001

## Project Overview

I completed a hands-on IT support project using my MacBook Pro to practice system inspection, network troubleshooting, and technical documentation.

## What I Practiced

- Identifying computer hardware and operating system information.
- Checking installed memory and storage usage.
- Identifying network interfaces and IPv4 configuration.
- Finding the default gateway.
- Testing network connectivity using ping.
- Checking DNS resolution and configuration.
- Recording diagnostic commands, results, and interpretations.

## Tools Used

- macOS System Settings
- macOS Terminal
- Built-in commands such as `sw_vers`, `ipconfig`, `route`, `ping`, `nslookup`, `networksetup`, and `scutil`

## Key Results

- Identified the computer's hardware and operating system information.
- Successfully tested connectivity to the local gateway and a public IP address.
- Successfully resolved `google.com` through DNS.
- Documented 12 diagnostic checks and their results.

## Skills Demonstrated

- Basic computer diagnostics
- Network troubleshooting fundamentals
- Command-line usage
- Technical documentation
- Interpreting diagnostic results

## Project Scope

All checks used built-in macOS tools and read-only commands. No hardware was removed or replaced, and no destructive changes were performed.

## Learning Outcome

This project helped me connect CompTIA A+ concepts with practical troubleshooting tasks on a real computer. It is part of my continued development in IT support and technical problem-solving.
