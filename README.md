# Mac Computer Diagnostics and IT Support Lab

**Project ID:** APLUS-LAB-001

## Overview

This project demonstrates entry-level IT support skills through read-only diagnostics performed on a MacBook Pro running macOS Sequoia.

## Objectives

- Identify hardware and operating system information.
- Review storage and installed memory.
- Inspect network interfaces and IP configuration.
- Test connectivity to a local gateway and a public IP address.
- Verify DNS name resolution and inspect DNS configuration.
- Document results and explain their meaning.

## Environment

- **Computer:** MacBook Pro (16-inch, 2023)
- **Processor:** Apple M2 Pro
- **Memory:** 16 GB
- **Operating System:** macOS Sequoia 15.6.1
- **Tools:** macOS System Settings and Terminal

## Diagnostic Activities

The project includes 12 documented checks covering system information, storage, memory, network configuration, connectivity, and DNS.

## Tools and Commands

- `sw_vers`
- `networksetup`
- `ipconfig`
- `route`
- `ping`
- `nslookup`
- `scutil`

## Safety and Scope

All checks used built-in macOS tools and read-only commands. No hardware was removed or replaced, and no destructive changes were performed.

## Learning Outcomes

This project provided practical experience with basic computer diagnostics, network troubleshooting, command-line tools, result interpretation, and technical documentation.
